# 📜 esp-pc-util

A smart desk pc utility

## Features

- HID interactions (Volume UP/DOWN/MUTE, Track PREVIOUS/PAUSE/NEXT)
- Screen customisation via desktop app (Wallpaper, Colors, Brightness...)

# Build

## Components

- ESP32S3 (N16R8)
- 3x Push Buttons
- Rotary Encoder Module (EC11)
- 2.8 in tft lcd (ILI9341)
- Cables
- Case (Optional)
